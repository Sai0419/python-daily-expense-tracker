A beginner-friendly Python project to manage daily expenses.

- Add daily expenses
- View recorded expenses
- Calculate total spending
- Simple menu-based interface

- Python 3

1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run the command:

   python expense_tracker.py

This project helps me improve my Python programming skills
and understand functions, lists, dictionaries, and loops.
